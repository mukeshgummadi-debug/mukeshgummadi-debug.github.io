# Mukesh Gummadi — Portfolio Website

A responsive, static portfolio website prepared for GitHub Pages.

## Files
- `index.html` — page content
- `styles.css` — responsive styling
- `script.js` — mobile navigation and current year

## Publish with GitHub Pages
1. Create a GitHub repository named `YOUR-USERNAME.github.io` (for a user site), or any repository name for a project site.
2. Upload the three website files (`index.html`, `styles.css`, `script.js`) to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the site. The URL will be shown in Settings → Pages.

## Before publishing
- Replace the profile-photo placeholder in `index.html` with your own image when ready.
- Verify all dates, company descriptions, tools and project wording.
- Add a professional email address only if you want it publicly displayed.
- If using a project repository rather than `YOUR-USERNAME.github.io`, GitHub Pages will publish at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Accuracy notes
The page uses the career information supplied in the conversation. It does not invent job titles for the listed employers, email addresses, client names, quantified AI productivity results, or unverified project outcomes. The project cards are explicitly described as representative case studies.
